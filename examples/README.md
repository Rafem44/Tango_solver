# Example Puzzles

This directory contains example Tango puzzles in text format.

## Format

- `.` represents an empty cell
- `0` represents a zero
- `1` represents a one
- Lines starting with `#` are comments

## Files

- `puzzle1.txt` - The puzzle from the algorithm description (5×5)
- `puzzle2.txt` - A simple test puzzle (4×4)

## Creating Your Own Puzzles

Create a text file with your puzzle following the format above. Each row should have values separated by spaces.
